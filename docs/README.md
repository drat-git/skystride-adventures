## Historical class-project material

[Earlier verification](VERIFICATION.md) and the [Sprint 2 checklist](REQUIREMENTS_CHECKLIST.md) describe their dated milestones. Their old pending items, placeholder AI, fixed-grid assumptions, account counts, and email-confirmation steps do not describe today's release. Current behavior is documented in the guides above.

Report specifications, traceability, diagrams, and generation scripts are separate assignment artifacts. Documentation updates do not regenerate or claim to complete the report, presentation, or human submission work.

Raw verification outputs, source-document copies, private fixtures, and packaged builds stay in ignored `output/`. Public download archives are attached to GitHub Releases rather than committed into Git history.
